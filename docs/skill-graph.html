La Casa — the 25 skill nodes (PRD §6)

How to read it: every box is one teachable unit — a grapheme (letter-pattern → sound, left tree), a sight word (memorized whole, top right), or a vocabulary/cognate word (right). Arrows = prerequisites. ⚑ = Spanish-L1 confusion set (sounds Spanish doesn't have — the drill targets). The yellow bar is mastery (0–1, EMA of attempts, decays over time). A node is on the frontier (terracotta ring) when all its prereqs are ≥ 0.8 mastered and it itself is < 0.6 — story content always targets exactly one frontier node, and the validator only allows words built from mastered pieces + that one target.

Decision #2 in plain terms: a fresh install (top) has a 14-node frontier of the easiest pieces — short vowels, sight words, cognates — so early beats teach "a/i/e-o-u" level content and the validator can barely build sentences (almost no mastered material to write with). The bundled demo state (bottom) assumes the kid already reads CVC words + knows the grocery words, so the frontier sits at the interesting Spanish-speaker pain points (sh, th, v/b, s-clusters…), beats read like real little stories, and the debug overlay shows a landscape that's already half-lit. The demo plays through the bottom graph; a real new learner would start at the top.
