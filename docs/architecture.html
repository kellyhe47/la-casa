The Learning Graph, technically La Casa · how one JSON graph drives content, difficulty, and language — and how content scales

1 One node, one loop

Everything the system knows about the learner is ~25 nodes. Each node is one teachable unit (a grapheme→phoneme mapping, a sight word, or a vocabulary item) carrying a single mastery value. Every graded interaction in the game — a shelf tap, a mic utterance, a magnet spelling — resolves to deterministic writes on nodes. No LLM anywhere in this loop (ADR-0001).

2 Three queries drive the whole game

The graph is read three ways, and each read answers a different question. All three are pure functions over node state — recomputed before every beat.

3 One session, one arc

Nothing persists between sessions. Each ¡Jugar! seeds the graph from a bundled mid-progress state (CVC + basics mastered, frontier on the Spanish-L1 confusion set) so a single ~5-minute playthrough shows the full loop: frontier word introduced → missed → corrected → spelled → read aloud in a sentence, while independence climbs from band 3 to ~8 and the Spanish scaffold visibly fades.

4 How content scales: everything above the engine is data

The engine (graph + grading + validator + prompt assembly) never changes. Three orthogonal data axes multiply on top of it — a new theme, a new grade band, or a new home language is JSON + art, zero new code. The LLM fills slots inside authored templates; the validator guarantees whatever it writes is readable by this kid; when content runs late, the fiction waits in character — idle animations and ambient house sound, never a spinner or canned stand-in.
